# Provenance and validation boundaries

This research repository contains a transparent, executable reconstruction of the Border Core method. Its source is not asserted to be the missing original implementation. Some reference outputs have been matched exactly by executable checks, which verifies those cases but does not prove general equivalence.

The included synthetic benchmark has four generator families and repeated random seeds. Repeated seeds within one family are not independent families; family-block significance tests should be interpreted with the correct small effective sample size. An externally curated benchmark with independently documented labels has not been completed as part of the archived experiments.

The `results/` folder includes exploratory comparisons of post-clustering geometric contact merging with simple controls. These comparisons were informed by preliminary investigations and should not be represented as a pre-registered confirmatory experiment.
